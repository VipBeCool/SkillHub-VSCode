# SkillHub VS Code Extension

> 🚀 AI 技能管理助手 (SkillHub) 的官方 VS Code 插件

SkillHub-VSCode 是一款让开发者无需离开编辑器，即可快速浏览、安装和管理 AI 技能的轻量级 IDE 插件。它是 [SkillHub 桌面端](https://github.com/你的用户名/SkillHub) 的最佳伴侣，支持无缝衔接本地技能库与云端能力。

## ✨ 核心特性

- **无缝集成**：在 VS Code / Antigravity / Cursor 中直接管理 AI Skills。
- **一键安装**：发现喜欢的技能，一键将其载入到当前 Agent 的工作流中。
- **与桌面端联动**：读取本地 SkillHub 数据，实时同步技能状态。
- **轻量快捷**：告别繁琐的路径配置，专注代码本身。

## 📦 安装与使用 (开发中)

> 该插件目前正处于积极开发阶段。

1. 克隆本仓库到本地。
2. 使用 `npm install` 安装依赖。
3. 在 VS Code 中按 `F5` 即可启动扩展开发宿主进行调试。
